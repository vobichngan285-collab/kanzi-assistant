# 蓝星 OpenOCR 实时视频实验 v0.1.3
基于上一像素实验v0.1.1及原图输入源码v0.1.2 5e785c4d91cd9c2d8b8a8cfb53c9e353115dfe77，同实验包com.vobich.bluestar.openocrlab.pixel versionCode3，不改正式版。照片原图无固定像素选择或24MP人为上限；仍受实际内存、协议和设备限制。
手机：枚举常规YUV_420_888和Surface支持尺寸，按YUV像素数降序测试合法双输出组合，先同尺寸再较小预览；实际4秒窗口平均至少5交付帧/s为初步可用判据（非长期稳定或30fps保证），失败/10秒无通过自动下探。高分辨率静态专用列表仅记录不混为视频能力。OCR前预览探测，随后默认运行原本实时OCR，可暂停OCR单独测视频。记录实际YUV、Surface、View、交付FPS、基于收到帧时间戳的采样FPS、捕获回调FPS、累计帧/完成间隔等。仅后摄默认逻辑相机。
C110：复用已验证HTTP启流及RTSP地址、LibVLC3.6.5和网络恢复，独立前台页面。读取当前轨道及VLC输出布局（未知标unknown），使用与原生可见尺寸一致的Surface，尺寸不一致不取帧；PixelCopy全Surface到等尺寸Bitmap，不宣称直接解码YUV或像素级无损，布局/旋转/黑边及实际内容仍需真机验证。VLC统计若公开可用记录解码/显示/丢帧计数及差分FPS，未知明确标记。没有猜测改变固件视频档位的命令，不宣称是相机所有固件设置的最大流。退出释放VLC并恢复进程网络；实体快门监听在原首页，离开时停、返回时按原设置恢复。若相机仍在视频模式需用户切回拍照模式。OCR仍一帧在途、原逐行TTS和去重、约1秒间隔，无云端。
视频诊断累计在本地有界140k字符，主页/预览可一次复制，不保存识别原文或图像。冻结v0.4.8核心和资产不改。CI仅编译/核心/签名校验，最高实际视频尺寸、帧率、画面是否完整、内存及长期运行待真机验证。
