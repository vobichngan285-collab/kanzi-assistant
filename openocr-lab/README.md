# 蓝星 OpenOCR 双模型实验 v0.1.0
独立包，复用已经真机成功的 YOLO26n-Text ONNX，校验上版 APK、检测报告及模型哈希。OpenOCR 固定源码 1ccfc6ee6161f7133b192e16af3a9265273997ba，官方 develop0.0.1 权重。RepSVTR 使用官方 ONNX；SVTRv2 使用原权重严格加载及 ONNX 导出，不重新训练/量化。官方 BGR、48 高、动态宽度、零右补边、CTC blank=0、重复折叠、原字典加空格；CI 对照 PyTorch/ONNX 同图结果和中文合成样本，不通过不发包。两模型 CPU4 串行，单模型同会话两轮，同一 YOLO 框及透视裁剪，按水平行几何拼接，不让模型猜测或修正。检测可能产生字符碎框、遗漏文字或错误分组；主 ROI 可能排除其他区域；纵排及超长文字不保证准确，宽度最多960。首行和识别耗时不含引擎加载，det_plus_rec 另计检测，不能等同首次端到端或实际出声。本轮不接Gemma、不增加TTS、不用用户照片上传、不修改正式蓝星和旧实验。APK无网络权限，三模型内置。OpenOCR和YOLO的各自许可需遵守，商用前核验。真机速度、CER、金额正确率待用户同图测试。
