# 蓝星 OpenOCR 原图与C110实验 v0.1.2
基于像素与C110实验 v0.1.1 (0deb1f5e2b706c6d91035173e8a39bc797ae997e)，同包名 com.vobich.bluestar.openocrlab.pixel，versionCode 2。依据同一1950万像素照片四档实验及用户决定，取消照片像素选择和24MP固定解码限制，直接以相册/C110解码原图识别，不缩小、不放大，不承诺超出设备可用内存的图像可运行；可捕获的内存错误明确报错，不自动降低像素。C110原有JPEG传输大小安全限制及协议校验保持。DB1600默认及内部模型输入处理、冻结v0.4.8核心、官方/智能模式、CPU线程选择、TTS、单次诊断、C110事件接收和手机实时预览1080p优先路线不变。不改正式版、不加入云端，不添加累计日志功能。超20MP真机内存和稳定性未验证。旧像素实验独立归档保留。
