# 蓝星 OpenOCR Focus TTS v0.4.1
独立实验：基于 Focus v0.4.0 c5e20868f61a1bf41a937d99af4df68ee913188e。
保留四模式、原检测、识别、区域和行列算法以及原模型资产。默认CPU4、智能主阅读区。
普通模式仅识别一次，完成后自动用 Android 默认 TTS 引擎朗读非空原始识别文本（不含待核标记、诊断、Gemma或语义修正），按原行列顺序以空格和换行连接；不静默丢弃可疑原文字。可重读或停止。对照模式保留两轮/模式，不自动读，分别显示三模式原文。
复制结果及诊断保留本机诊断（含OCR原文，勿上传私人信息）。记录点击至原文就绪、TTS入队、首段开始及结束回调；回调不代表真实扬声器声音。默认系统语音与语速，不强制语言、不改语音设置。APP无INTERNET权限；外部TTS引擎是否离线取决于系统所选音色。独立包，不覆盖正式APP或Focus v0.4.0。
真机验证待完成：选同图单次识别、核对显示与朗读一致、首声实际听感、句间停顿、停止/重读、新图不串读、三模式对照；不要提交私人原图或原文。
