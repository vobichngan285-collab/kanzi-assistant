# 蓝星 OpenOCR 识别竞技场 v0.1.0
Independent package com.vobich.bluestar.openocrlab.recarena; derived from v0.4.8 4b52f658a9ec28f564b4ed77f14a97a60b477a63. Frozen RepViT-DB official 1600, one detection per run, then identical ordered quadrilaterals and deterministic original-resolution crop/rotation/BGR normalization per model. RepSVTR and SVTRv2 Chinese CTC reuse prior APK assets with original report SHA256; same dictionary, official dynamic 48-high input and batch six when supported. No changes to detector geometry, no filtering (scores logged), no semantic correction, no TTS/Gemma, no network or test photo upload. Sequential model sessions, first and second pass per model, selectable execution order and CPU4/6/2; reverse order to check thermal and allocator effects. Timings include load, first batch, crop/resize, tensor, session.run and CTC decode, and total recognition. PSS snapshots not peak; closing a session does not guarantee allocator releases all memory. Raw box IDs and text are copied locally. Model difference count is not accuracy; compare against human ground truth. Desktop synthetic smoke test checks real exported graph on widths 320/759/939 and batches 1/6, not accuracy or device performance. Original frozen apps untouched. ScriptMoE not bundled: separate export, licensing and runtime validation pending. No claim of phone validation until actual results.
