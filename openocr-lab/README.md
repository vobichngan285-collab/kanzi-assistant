# 蓝星 OpenOCR 实地朗读 v0.4.2
基于 v0.4.1 原文朗读版。默认 RepViT-DB，复用竞技场检测代码及同一发布APK权重，SHA256验证。保留YOLO26n切换，每次只运行一个检测器；原RepSVTR、字典、Reader、原阅读区算法及系统TTS保留。默认全图原框，沿用擂台去重、排序、竖框读取及待核逻辑。CPU4默认，DB及识别可选2/6线程，原YOLO固定4。复制诊断含全部原框与置信度，原文不自动纠错。ARM64，无INTERNET权限，系统TTS离线取决于设备。独立包，不修改正式APP；真机待验证。

## v0.4.4 adaptive experiment
Retains all manual modes and DB resolutions; new opt-in adaptive mode runs DB once, reuses focus and row planner. Requires a dominant region and at least four consecutive stable aligned two-column rows with regular pitch; substantial outside heading vetoes focus; otherwise falls back to raw quads. This is layout inference, not semantic scene classification. Only adaptive structured right cells with a unique matching original box use original crop; uncertain cells get one planned-crop retry; disagreements retain original and flag uncertainty (no digit/sign correction). Adaptive TTS announces uncertain cells and unread outside regions; manual modes unchanged. Logs route, evidence, latency, original crop counts, retry/conflict details. No model, thresholds, resolution or thread changes. Test DB1600 on same shop signs, price list, packaging, mixed scenes. Unit tests use synthetic geometry inspired by sample; device validation pending.
