# 蓝星 OpenOCR 主阅读区 v0.4.0
用户授权基于已验证v0.1.3继续主阅读区优化，停止复杂竖排研发。独立实验包，正式APP不变。精确复用v0.1.3发布APK中的YOLO26n-Text、RepSVTR、字典及原RowPlanner/ColumnPlanner/Reader；不改模型、阈值或原裁剪算法。默认CPU4（检测器固定4，识别器可2/4/6）。
新增纯几何区域规划：去除重复锚点计分、按文字尺度与邻接形成候选区域；考虑多行支持及相对竞争区域，不强制居中；若稀疏、多块竞争、疑似竖列或外部有较重要区域则回全图。保留原始检测框，区域外灰框显示及坐标日志；提示未读区域并提供全图入口，不能保证所有重要信息都被自动选中。焦点/全图模式增强待核提示（均值<0.75或最低<0.65或空），不删除或猜测金额，不复读；原v0.1.3区域基线保留原待核策略与相同列裁剪。对照模式同图共享一次检测，三种模式各两轮；总耗时为共享检测+对应规划+识别，不含加载和预览；PSS为采样非峰值。新增5项几何单测，CI校验原资产SHA、编译、签名、权限，真机性能需复验。
测试先用同价目表选择同图区域对照，检查十项金额/服务、充值及标题、ROI之外是否有需要阅读的字；再用两张不同类型横排照片检验多区域/偏心/稀疏情况。无联网、无TTS、无Gemma，不上传原图。旧版和发布均保留。
