# 蓝星 OpenOCR 整行优化 v0.1.1
原实验分支升级，独立包名保留v0.1.0。真机基线：3072x4096，YOLO438ms、44框16行；RepSVTR热态1281ms，检测加识别1719ms；SVTRv2热态6414ms，识别未改善，淘汰。复用已验证APK内的RepSVTR/YOLO/字典逐字节SHA核对，不再下载训练权重或导出。CPU4、同一CTC预处理/解码不动。新策略：主区域同基线，估计水平倾斜角、投影坐标去包含框、按中心聚行、间隔2.2倍行高内合并、20%行高留边、相邻行中线限制扩展，完整原像素透视采样。大列间距保留；不做词典纠错。默认旧/新/新/旧，同一次检测、同一Reader，记录首行、识别及检测+识别、规划时间、框数/宽度；冷加载单独。黄色旧框、青色新框、绿色ROI。可能误合并、漏掉未检测行、装饰误识、宽度960上限及纵排限制仍在。目标1–2秒和95%准确率未验证。无TTS/Gemma/网络，不改正式APP及旧Release。几何单测验证包含框、碎片合并、相邻行及大列间距。
