# 蓝星 OpenOCR 自适应裁剪 v0.3.0
独立实验包，保留原稳定版v0.1.3和竞技场v0.2.0。只保留YOLO26n、RepViT-DB两个检测器及原RepSVTR字典，全部从已发布v0.2.0 APK按固定SHA提取、逐资产校验，不改权重。默认DB、CPU4、全图单次、layout4自适应。保留layout0–3原行为用于对照。
新模式：原始长竖框独立保留，按右至左排列；不把竖列放入横排行列规划。横排保留旧规划合并碎字；单个独立原框使用其原始四边形，避免扩边和去旋转损伤，原框内多条独立长文本按几何间距拆回原框。最多六次弱置信或带符号数字的裁剪对照，保留主读结果，分歧明确待核，不根据词典或规则删减数字、正负号；最低字符置信度低于0.65或平均低于0.75也标待核。日志记录复核次数、原文和备选，仅本地复制。
竖排仍用原RepSVTR：边缘背景估计、双极性对比度投影、原有网格切分、保留字形纵横比例及背景色的横条重排。不是原生竖排识别器，复杂背景、书法、低对比、不规则字距、错切、混合阅读顺序仍可能失败。旧模式不改。无Gemma/TTS/网络，不自动上传图片，不改正式APP。CI验证模型资产、CPU推理、几何及投影单测、APK签名/包名/无网络权限；不等于真机准确率。请同一价目表和竖排海报先测DB layout4各两轮，与旧日志及YOLO同模式对照，特别检查金额和漏读；不达标则保留v0.1.3稳定方案。
