# BlueStar OpenOCR Arena v0.2.0
用户授权六模型：YOLO26n/s/m/l/x-Text + OpenOCR RepViT-DB，明确排除百度/Paddle。原v0.1.5冻结；同一RepSVTR、同一图片、CPU线程、同一扫描/后处理策略。默认全图单次、原始框识别（纵长框仍需字符重排）；可选四块高清及v0.1.4/v0.1.5/横排行列算法。手动单模型或全部，分别冷/热两次推理；逐个加载释放，识别器常驻，模型缓存到文件避免超大Java byte[]。日志保留原始框与最终框、坐标、文本、置信度、耗时、PSS采样（不是峰值），预览可按模型切换。无准确率自动评分，需人工原文核对；无Gemma/TTS。YOLO原厂固定尺寸ONNX（n为1280，s实测640；其他以CI实际形状为准），n复用已验权重，其余官方SHA校验；RepViT官方ONNX发布资产大小校验、记录SHA，官方BGR 960长边及32倍数、DB阈值0.3/0.6、unclip1.5，OpenCV矩形连续扩展近似pyclipper（不是完全一致）。因此跨模型结果含移植后处理差异。CI进行CPU推理形状及有限值检查，不等于真机准确率。独立包，原正式APP与实验Release不动。原v0.1.5同图总2650.5ms，文字质量退步，停止单独优化YOLO。
