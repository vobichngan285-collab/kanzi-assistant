# 蓝星 OpenOCR 混合排版 v0.1.4
v0.1.3价目表全部已知项目/数字正确，CPU4最快1116ms；竖排刮痧海报失败，15框仅4入ROI，输出S/A/空。此版保留v0.1.3横排模式和权重哈希；默认全图检测加四块60%重叠高清tile、坐标回映及近重复去重，快速模式只用全图检测。竖长框启发式分列，竖排右至左、列内上至下；将原图透视校正后用暗字投影估计单字区域，保持正向重排为横条再用原RepSVTR，未改权重。横排继续用原行列规划。混合区域先后顺序为几何启发式，不保证标题/落款语义顺序；旋转横排、浅字深底、书法、漏检整列及不规则字距仍可能失败，不能声称全面支持。疑似/空文本保留诊断；四tile增加耗时，快速模式可对照；输出每块方向/坐标/置信度。用户未授权Gemma/TTS接入，本版无。独立包，正式APP与旧Release不动。单测仅覆盖投影分割，不代表真机准确率。
