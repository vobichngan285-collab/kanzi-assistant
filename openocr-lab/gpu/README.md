# Independent OCR GPU research — stage 1
Frozen source: v0.2.0 verified APK (commit b499713f5cc9b737221f14ffa64181422b0f923f), RepSVTR and OpenOCRv2 CTC exact ONNX and dictionaries. DB and existing Android code are not changed. No eye-brain, language correction, quantization or new release.
First candidate MNN 3.5.0, selected for explicit OpenCL/Vulkan backends and dynamic shape support. ncnn Vulkan remains independent alternative. QNN is device-specific and static shape constrained; NNAPI is not proof of GPU execution. Framework feature claims do not establish actual graph compatibility.
This CI runs two independent model jobs: audit actual graph operators/opsets/shapes, convert FP32 using pinned MNN wheel, then compare full output tensors and greedy CTC text with ORT CPU on changing real input shape classes and synthetic text. No allowCustomOp, no shape freezing, no private image data. Tolerance rtol 0.003, atol 0.0005 plus exact decoded strings; a failure is diagnostic, not grounds for patching model semantics. Random tensors are numerical checks, synthetic inputs not accuracy evaluation. Host timings not phone or GPU benchmarks.
Next gate only for passing models: Android native runtime with explicit backend selection, capture actual device/vendor and per-op backend assignment / CPU fallback and transfer timings; compare same prepared input, raw CTC and cold/warm latency, PSS plus device memory where measurable. Verify GPU execution and compare whole recognizer before asserting acceleration. Do not silently fall back or claim GPU speed from selection flags. Preserve CPU baselines and require real-image equality/quality review. Target ~3x effective session-run speed for V2, not a measured claim.
