# 蓝星原厂权重分辨率实验 v0.2.1
独立实验应用，基于已发布 v0.2.0；正式蓝星和原厂 App 不变。使用原有官方 Q4_K_M 与 FP16 16x/4x 权重，SHA 校验、固定引擎及推理参数不变。默认 16x CPU6，模型常驻，原厂动态切片上限9。
- 新增原图/315万/224万（默认）/177万/79万/44万像素上限，不放大、不裁剪、保持比例；解码及 EXIF 修正后，原生 RGB 面积加权缩放，无 JPEG/PNG 重编码。原图模式保持原路径。实际输入和缩放尺寸、resize_ms、image_chunks、encoded_chunks、image_tokens 写入日志。
- 界面每500ms刷新当前阶段及总计耗时，vision显示实际图像chunk序号/总数及该chunk token，不把chunk数当作内部切片数；底层一个chunk内可能有多片，不能显示其内部百分比。识别中可复制阶段诊断；停止仍需等待当前视觉块返回，不承诺立即中断。没有新增GPU/NPU。
- 首字指标不含冷加载；总计界面和首段语音入队时间包含冷加载。语音入队不代表扬声器实际出声。
- 原厂权重和原图均无需重新下载；相同包名尝试覆盖安装，若实验签名不同，请先保留下载的模型文件，再仅卸载旧实验包并导入，勿卸载正式蓝星。实际准确率/速度需真机对照，不保证1～2秒。
