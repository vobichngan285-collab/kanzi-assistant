# 蓝星原厂权重 CPU 专项 v0.2.2
原厂 Q4_K_M 与 FP16 16x/4x 文件、原生动态切片9、OCR提示、六档分辨率不变，不改正式蓝星。原厂ARM显式fp16/bf16编译参数（本实验只针对MT6991），固定同一引擎。新增无模型FP16×F32矩阵1152×1152×256三轮，对照CPU4/6/高性能4核请求，校验输出数值。第0轮含冷图执行；1/2为热轮。GGML特征和OS HWCAP记录，编译标志/特征不等于使用硬件内核。
- 只给实验构建的固定引擎插入两个计数器，统计线程0实际进入通用F16 MUL_MAT分支或KleidiAI FP16返回成功次数；不是全部算子、不是逐指令或精度证明。每个完成视觉块记录wall/process CPU耗时和两个计数；识别中可复制已完成块日志。
- 识别配置：默认旧运行参数、视觉图预初始化、CPU4高性能核心调度请求、原厂式预初始化+batch/ubatch2048；切换配置时重载。预初始化主要是分配/探测，不等于完成图片编码。高性能核按当前允许CPU的capacity或最高频率排序，只有调用线程affinity经回读；后续线程可能继承，未证实所有运算线程绑核。无可用信息则不绑核，退出恢复调用线程affinity。
- 停止仍在视觉块结束后生效。真机性能和精度未验证。无需重下模型，签名冲突只卸载旧独立实验APK，保留下载文件。
