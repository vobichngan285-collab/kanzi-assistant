# Gemma 560 quantized FC restoration
Host-only experiment on the existing hybrid branch, based on verified v0.1.6. Restore the original 112 INT8 weights, scales, zero points, axes, and hybrid FC input quantization modes by exact dequantized float hash, without arbitrary requantization or changing vision budget. Fail closed on unmatched weights or incompatible FC types. Retain 280 and 560 signatures; benchmark full and padded inputs against the exact corrected FP32 encoder. Passing synthetic feature and speed screening is not OCR acceptance or proof of GPU execution. No APK published by this workflow. Next gate: full model reassembly and same-image OCR comparison, followed by Android GPU validation. No user photos used.
