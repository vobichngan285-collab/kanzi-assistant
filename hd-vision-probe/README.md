# MiniCPM-V4.7 fixed vision HD host probe

Independent research from stable v0.1.11. A 448/16x control, B 448/4x (skip intermediate merger, 256 visual tokens), C 896/16x (256 tokens). All compare one static square, not native dynamic slicing. Pin converter a395b4967fa9e879a5de548d83399b4be2487b1e and HF checkpoint 984a89aafcd5160164f4f0d04b4be0f4eec03cb8 per upstream shipping recipe. Run HF native visual features, adapted pure torch, and actual fp32 LiteRT TFLite export/interpreter against identical pixels. Require correct IO shapes, finite features, end-to-end mean cosine >= .999 and min >= .98. Synthetic Chinese price chart; no user photos. Reports only, no model weights or APK published. 896 may hit runner memory/time limits. This does not yet test full text generation, quantization, 1D versus native canvas M-RoPE, FastVLM token injection, metadata, Android speed or OCR accuracy. Successful probe is prerequisite to repacking the original decoder with the new encoder and adapter, retaining executor metadata and validating generated text. No changes to existing APK, model, or production app.
