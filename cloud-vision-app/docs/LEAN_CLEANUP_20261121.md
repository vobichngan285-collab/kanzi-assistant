# 蓝星向导 v1.0.71｜只减肥、不重造：无效入口与历史实验清理

## 范围
- 基线：已发布、用户真机表示有提速体感的 v1.0.70 `12062f26b224d6a63c35384c660861513732fd25`。
- 独立分支：`exp/lean-cleanup-20261121`。本版不合并 main、不覆盖老 Release、不修改用户存储的模型、API Key、任务、TTS 音色、C110 Wi-Fi 配置。
- 核心保护：`CloudVisionClient` / `CloudProviderStore` / `CloudAsrClient` / `LayoutParsingClient` / `TargetVisionClient` 与用户原有 OCR SSE、智谱逐行提示词和数字诊断保持原版。保留原厂 C110 3012/3016/3001/2015/1001、静音9011/灯9038、LibVLC3.6.5、Camera2、USB UVC、TTS和快捷拍照。

## 已实施的精简
1. 统一设置首页从七个入口合为五个：**相机／语音与提示／云端AI／任务管理／高级与诊断**。提示音/振动并入语音页，上次识别、录音诊断和运行日志归入高级页。不删除这些功能，不改变配置键名。
2. C110机身设置从逐行显示 9 个声音/灯光操作，整理为 **连接Wi-Fi、机身提示音、指示灯** 三项。原声音9011/灯9038控制和已有延时值不变；自定义5～600秒入口仍可用。
3. 删除统一设置里已不可达的 `providers`／`models`／`ocr-models` 旧页面。实际可用的 OCR/视觉/ASR 自定义厂商选择仍统一走 `provider-role` 页面，保持单一✓生效模型逻辑。
4. 删除 `MainActivity` 内不可达的第二套 `C110LivePreview`，以及旧任务弹窗、旧模型/语音/画质弹窗、隐藏顶部工具栏和不可见状态控件。**独立 `C110CameraActivity` 的视频/快拍完整保留**，主程序既存直达高清1001快拍逻辑继续可用。
5. 删除未在 manifest 注册且无主程序调用的分辨率实验Activity、RTSP/预览探针、音量快捷实验、旧任务宫格弹窗。对应历史专项Java测试也从本分支移除，旧分支/提交记录可追溯；`TaskDesktopActivity` 现役4列任务宫格保留。
6. 删除没有界面调用的 **OEM 4003单文件删除实验代码**（`C110WifiCamera` + `C110CameraActivity` + `C110DeletePolicy`），降低误删除风险；原厂1001快门、照片列表及JPEG下载流程保持不变。
7. 经逐个静态扫描本应用所有Java文件，未发现任何 `androidx.media3` / ExoPlayer 使用，尝试从 **app模块** 依赖中去除 Media3 ExoPlayer/RTSP/UI。仍保留必须的 LibVLC 3.6.5 与 UVC 模块。最终实际 APK 是否瘦身、是否影响构建，以CI结果为准，不能在编译前承诺。
8. 调整版本为 `versionCode 80`，`versionName 1.0.71-lean-cleanup`。调试包身份维持 `com.vobich.bluestar.c110plusquick159`，不新建Launcher图标。

## 特别保护与限制
- 绝不把检测界面“当前时间/CPU/网络速度”日志代码移除；运行诊断对后续 OCR 性能排查必需。
- `MainActivity.cloudBusy`、单线程 `encoder`、相机状态机、Wi-Fi租约、手机/USB帧同步、扬声器TTS与声音/振动协议不重设计。本版是**结构减肥**，不宣称直接缩短服务端推理时间。
- C110 独立预览界面的隐藏顶部控件和铺满变换仍然保留；它们与真实VLC画面布局相关，需另有真机验证后才能安全删除。
- 删除旧音量快捷试验不是删系统音量键功能：旧实现从无当前Activity的触发引用，本版仍没有新增音量键快拍。
- 本版必须先跑完整Gradle arm64编译、纯Java测试、对照diff和APK包名/资源/唯一Launcher及LibVLC/UVC验证，之后才发布独立预览Release。
- 上述源码静态可达性判定不等于覆盖所有Android反射或动态调用；真机仍需验收手机快拍、USB预览、C110预览和高清拍照、FlashX／高精度／千问SSE第一声，以及语音引擎切换、所有设置和Task编辑。
