# v1.0.91 主页六宫格与相机电量
基于已发布正式版 v1.0.90 e1df4221a99fec313eb4db8545cd7e49c6fc5afc，不合入画质实验。保留正式包 com.vobich.bluestar.c110plusquick159 及保益桥接器。用户批准图示布局：无应用标题栏，深蓝背景；顶部运动相机状态卡（Wi-Fi状态、电量、快速连接）；中间3列2排50dp图标，快捷拍照/实时预览/朗读任务/阅读模式/连接相机/设置；底部主页/预览/按住AI原逻辑保持。用真实Android Button作为完整点击及读屏焦点，图标不另占焦点，文字可随系统字体缩放，内容可滚动。连接调用原Home唯一Wi-Fi租约，不创建额外WifiNetworkSpecifier或断开网络，原首次配对权限及自动连接保持。
电量依据 Novatek NT96660 Wifi Command Application Note 2016-04-06 §5.3.19（https://www.mputek.store/filedown/Survey3-WIFI-Manual.pdf），只读GET 3019无参数。仅已有相机Wi-Fi Network.openConnection、固定192.168.1.254、禁止重定向、限制超时和响应8KiB；仅Home前台，3秒检查连接变化，60秒查询电量，手动连接触发刷新最短10秒，单线程单请求；已有快捷拍照pending/快门取图期间不发起电量请求，离开主页不再发起，旧回执按代数及Network身份丢弃。已发起的只读短请求不等待阻塞快门或主线程。响应验证Cmd=3019 Status=0，0–5按公开参考档位标注（参考），明确返回带百分号才显示百分比，未限定数值6–100标为待确认，失败/断开电量未知，不假造百分比。不同相机固件枚举定义可能不同，用户C110还需真机验证；不把参考档位当精确百分比。无新权限、无持久化电量、不向云端发送相机状态。屏幕阅读器可读实际返回值。
测试：检查3×2及标题取消、快速连接、顶部连接/断开变化、电量真实回执、底部3导航和按住AI。保益双击仍只执行一次1001→OCR→TTS；手机/USB及C110预览和高清拍照原样；原App签名/包名/Launcher/外部QUICK_SHOT合约保留。编译、解析单测和静态范围检查不等同于真机电量和读屏验收。
