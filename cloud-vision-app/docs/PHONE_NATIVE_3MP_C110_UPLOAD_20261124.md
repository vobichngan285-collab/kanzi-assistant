# 蓝星向导 v1.0.82：手机真正原生300多万 / C110高清上传尺寸实验
2026-11-24；原仓库 `vobichngan285-collab/kanzi-assistant`，基线 v1.0.81 commit `3273c779db21ac2d2647efe335f7bb43385ca843`，实验分支 `exp/phone-native3mp-c110-upload-20261124`。

用户授权“可以现在开始”。目标是**保留文字细节的前提下更快朗读**。已有v1.0.81日志：原生约775万上传原图慢于同片缩1440P；720P预览更快。仍需实测验证手机原生370万拍照是否比先拍775万再缩370万具有速度优势且不丢小字。

手机相机→“手机原生拍照像素”有默认原生8MP或真正原生300多万；只使用Camera2报告的ImageFormat.JPEG尺寸，300万含至400万不含，偏好2560×1440。如果设备不支持，则真拍照报错，**不改成800万缩图冒充原生370万**。在“手机高清上传分辨率”选择1440P即可比较：A真正8MP拍照→缩370万；B原生3–4MP拍照→等比上传最多370万。其他原上传三档和快速预览保持。切换Camera2原生JPEG需要重启手机Camera2会话；日志`camera.phone_native_mode`=0或1、`camera.raw_width_px/raw_height_px`是实拍尺寸、`jpeg.width_px/height_px`是上云尺寸。

“设置→相机→C110运动相机→运动相机高清上传”独立设置原图（默认）或1440P。只有在原厂1001真快门和Wi-Fi取得原JPEG后，并在需要时按原功能裁剪取景区域后，再按比例缩小上云JPEG到至多2560×1440；原图模式 byte[] 完全无重编码；缩图不能放大、小图保持小、失败停止上传而不是偷换原图。适用于主页C110快捷高清、C110预览页高清快门、MainActivity C110高清。C110实时预览PixelCopy以及手机快速/USB不受影响。为了降低大图内存，满足条件时JPEG解码inSampleSize=2，输出质量90。C110原厂3012/3016/3001/2015/1001与Wi-Fi、RTSP/LibVLC/机身灯光提示音、安全快门锁**不修改**；不将以往C110+实测当作未测试普通C110的兼容证据。

两条相机路线各对比同样模型/距离/场景/网络与小字精度，至少5次每档。C110 Home/预览页增加`c110_photo`数值诊断，其中`capture.total_ms`从照片下载完成时起算，不可与主拍照按钮含1001/Wi-Fi时间的总时长混为一谈；Main C110沿用旧诊断并显示`c110.upload_mode`、实际上传JPEG像素。临时取消任务时可能缺少完整云端指标。整个日志不保存任何照片/文字/音频或密钥。TTS首音频回调不保证真实扬声器出声。严禁卸载旧debug包造成Keystore密钥丢失。

本实验不修改云模型、提示词、Base64/HTTP、流式朗读和TTS、USB、运动相机原厂协议或既有摄像头快速模式。CI编译成功并不代表真机、原生可选尺寸、小字识别或耳听速度已被验证。
