# v1.0.97 C110 lock-screen listener

Single user toggle on Home, existing ENABLE preference retained; removes duplicate Home camera tile and Settings toggle, keeps interval and auto-delete settings. Battery icon 46x25dp, unchanged OEM state mapping and drawing. User-enabled connectedDevice foreground service owns one watcher, independent Context-based existing JPEG recognizer and ding, CPU partial wake lock and Wi-Fi lock while listening, no screen wake, camera or microphone use. Android notification includes stop action (visibility depends on notification permission). Home lock/unlock does not restart watcher/baseline; service yields to Blue Star's own non-Home screens to avoid dual camera I/O and TTS; resumes after those screens stop. Existing Home manual/voice gates route into same watcher. No boot startup or forced restart; prior enabled preference starts on visible Home. Wi-Fi still uses existing verified network/lease; if Home is destroyed or OS disconnects local-only Wi-Fi, manual reconnection may be necessary. Deep Doze/vendor battery restrictions and third-party TTS may prevent immediate delivery; device acceptance required. No automatic battery exemption or lockscreen bypass. Existing cleanup remains unchanged.
