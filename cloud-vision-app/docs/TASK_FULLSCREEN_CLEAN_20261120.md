# 蓝星向导 v1.0.64 — 朗读任务独立全屏页面

## 目标与原因
用户 v1.0.63 真机截图确认旧任务选择器是半透明模态弹层，主页菜单和文字透出重叠；顶部「阅读」与 X 无关按钮、多余铅笔图标，用户否决。用户亲自确认干净全屏效果图并授权实施。本版本严格只改用户从主页点击「朗读任务」后的界面，不重写相机、语音、OCR、Wi-Fi 或其他设置。

## 操作
- 打开主应用仍是原有深蓝竖排主页；点击「朗读任务」直接打开 Manifest 已注册的 **TaskDesktopActivity**，不再实例化 Home 的 TaskDesktopOverlay/Dialog。真实 Android Activity 使用完全不透明的 #091B32 背景。
- 上方左侧「‹ 返回」；屏幕居中「朗读任务」；下方 4 列、每页 12 宫格，适合现有 5 个默认任务+添加任务图标。**不出现旧主页、顶端阅读按钮、关闭 X、底栏及常驻小铅笔**。超过 12 项才显示页码/上一页/下一页。
- 单击任务：沿用 TaskCatalog.select() 持久保存并自动返回主页；单击添加：打开任务名、AI 提示词、图标编辑并保存；长按不拖动：弹出编辑/隐藏或删除选项；长按后拖动：原生 Android startDragAndDrop 重排序，沿用 TaskOrder.move + TaskCatalog.saveDisplayOrder；页面可切换，隐藏系统任务可在设置恢复，删除自定义任务有二次确认。操作中临时弹出的确认框并非主页叠层。
- 不更改 TaskCatalog 已有稳定任务ID、提示词、排序 SharedPreferences，也不覆盖此前的个人任务和 API Key。

## 不受影响
原 Home 快捷拍照和 Boyue 双击触发器（包名 com.vobich.bluestar.c110plusquick159）、C110 OEM 3012/3016/3001/2015、1001 原厂高清快门、150ms VLC 视频、变焦 JPEG 云端区域裁剪、手机/USB 摄像头、最近照片 AI 按住问答、广荣微软 TTS、9011/9038 和统一设置全部不动。原 TaskDesktopOverlay 类仍留给其他已有入口，不在本次 UI 修复范围。
