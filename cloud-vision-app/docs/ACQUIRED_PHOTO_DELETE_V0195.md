# v1.0.95 C110 acquired-photo cleanup

Opt-in cleanup is triggered at validated full JPEG acquisition, not recognition. Both native remote shutter and physical watcher enqueue the exact acquired path and SHA-256 in one independent serial executor. No enqueue in the verification-only download. Each delete rechecks switch, same network, standard C110, OEM capability, path and content; no bulk deletion or retry. New OCR, target search, ASR, Activity transitions and recognition cancellation do not cancel queued cleanup. Disconnect, disabling cleanup or failed verification can leave original files. Live frames do not create SD JPEGs. Only photos actually downloaded by the existing latest-photo capture policy are eligible; unread burst frames remain. Camera I/O contention and live-preview firmware deletion behavior require device verification. No image/path/key logging; Android log records only outcome.

Acceptance: test each of the physical, remote quick-shot and live-preview high-resolution routes with cleanup on/off, target found/not found, cloud failure and immediate next capture. Verify unrelated files remain and monitor deletion failures and latency on the real C110.
