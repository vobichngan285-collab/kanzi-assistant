# C110+ 原生内存卡照片尺寸独立实验 v0.2.0 — 2026-11-19

## 为什么更正

用户提供购买页面截图，商品详情型号清楚标注 **SJCAM C110+**，并明确确认实际购买为C110+。上一版v0.1.0根据**标准C110**的675配置推断3M/2K为`1002/par=5`，针对C110+是错误映射，**旧包③设置2K绝对不要使用**。之前的实时视频/静音/拍照用户真机已经成功；纠正商品型号不意味着这些成功实验失效，但应当重新审查将来任何以型号白名单为依据的设置或删除操作。

## 直接核验原厂SJCAM Zone APK中的C110+配置

用户此前上传的原始APK：`bdcc3db17ea0e26aecaf22bc01fe99be.apk`，197,152,487字节，SJCAM Zone 6.7.3.16。直接从APK内读取以下**四份**配置，而非引用其他型号：
- `assets/cparams/580-C110+$1.0.7.json`
- `assets/cparams/580-C110+$1.0.8.json`
- `assets/cparams/580-C110+$1.1.2.json`
- `assets/cparams/580-C110+_AIC$1.1.8 AIC.json`

上述四份 `International[0].section_array[10].row_array[0]` 的 `Photo Size` 项均是 `cmd=1002`，有序档位完全一致：

| 0-based 参数候选 | 原厂列表 | JPEG 标注像素 |
|---|---|---|
| 0 | 20M | 5888×3312 |
| 1 | 16M | 5376×3024 |
| 2 | 14M | 5008×2816 |
| 3 | 12M | 4640×2608 |
| 4 | 10M | 4320×2432 |

原厂DEX中的`LYCamera.setting`使用`Command.setCmd`/`setPar`拼接WiFi HTTP命令，曾验证的1002为拍照尺寸。**这属于原厂配置的候选映射，不是用户C110+当前固件已经验收的结果。** 用户此前的相机实际生成过5888×3312完整JPEG，与**C110+的20M默认档**高度吻合；标准C110另一套675配置最高15M，不可再作为其控制依据。

## 本轮最小实验

- 独立GitHub分支 `exp/c110plus-native-photo-size-lab-20261119`，单独`:c110photosize`程序包（`com.vobich.bluestar.c110plusphotosize`）。保留以前的构建和全部正式蓝星代码，**不实现全屏/旋转**。
- 只读探测标准C110家族已知的`3012`/`3002`/`3014`，允许真实固件把C110+简写为C110或别名C110_PRO，但**不能仅由这几个型号字符串决定可以写入设置**。
- 用户点击②，仅发送一次已验证的`3001/par=0`拍照模式和`1001`真实快门。通过前后文件差集唯一确定新SD卡JPEG，下载完整原图，校验JPEG头尾并读取实际宽高。不保存手机相册，不上传云端。
- **只有实际获得5888×3312的20M基线时，③按钮才解锁**；用户再阅读确认持久设置风险后，且固件3002声明1002，才发送一次`/?custom=1&cmd=1002&par=7`，消耗一次性授权，绝不自动重试、也绝不猜测原档恢复。
- 用户点击④重新拍一张原图，读取真实SD JPEG宽、高、原图字节数、下载耗时。只有尺寸**2560×1440**才说明该次JPEG确实是2K，HTTP 200/Status0不是充分证据。
- 由于可能存在相机设置持久保存，实验后若需恢复大照片，请**通过原厂SJCAM Zone手动改回20M**。不会发送任何其他照片尺寸或未知参数；不删除卡内文件。
- 该实验包仅需要INTERNET和ACCESS_NETWORK_STATE权限，手机需**先在系统WiFi连接C110+热点**。不含自动连接、RTSP、云OCR、TTS、音频、摄像头权限、照片上传、全屏、固件升级、删除或格式化。
- 用户每档只需点击①②③④，最后复制数值诊断发送给助手；注意每次②和④都会真的拍照写入相机内存卡。

## 本轮正确验收

1. 确认实体为C110+，打开Wi-Fi后在系统连接，运行 **C110+ v0.2.0**，不要再运行错误v0.1.0设置实验。
2. ① 查看1002是否由固件声明；② 拍一张20M基线（期待5888×3312）；如果不是20M，**不允许写设置**，先反馈日志。
3. ③ 明确人工确认后只试一次`1002/par=7`；④ 再拍图检查相机**SD卡上新写入**照片实际是否2560×1440。
4. 复制全部诊断；如有更改，通过原厂App恢复所需尺寸。**CI成功不代表真机成功**。
