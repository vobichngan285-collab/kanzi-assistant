# C110 原生 JPEG 写入尺寸：最小真机实验 (2026-11-19)

## 用户任务

只验证**照片真实写入相机内存卡的 JPEG 像素尺寸**是否可以由原厂相机控制指令改变。不做全屏、旋转、云OCR/TTS、图片上传、压缩重编码、内存卡删除、灯光/声音、视频预览或固件升级。不得覆盖正式蓝星向导和 C110 之前已成功的实验 APK。

## 原厂证据：直接重新打开用户的 APK

- 文件：用户原厂 SJCAM Zone 6.7.3.16，bdcc3db17ea0e26aecaf22bc01fe99be.apk；APK内原始 classes5.dex 与 assets/cparams/675-C110 的设置 JSON。
- 原厂配置对应标准C110：
  - assets/cparams/675-C110$1.0.1.json、675-C110$1.0.4.json、675-C110$1.0.7.json；row 模式 model=0,model_type=2, title Photo Size, cmd="1002"。
  - 数组（严格依原APK列出）：0→15M 5200×2928，1→12M 4640×2608，2→10M 4320×2432，3→8M 3840×2160，4→5M 3200×1808，**5→3M 2560×1440（2K候选）**，6→1M 1440×816。
  - 没有标准 1280×720 JPEG 档；录像 2002 的 720P 不可错用作照片大小。C110+ 的配置表与标准C110不同，严格不试其他机型。
- classes5.dex 原厂方法 Lorg/jght/sjcam/zone/camera/LYCamera;->setting:
  - code_off 0x18d2fc 与 0x18d24c 实际调用 LYCamera$Command.setCmd、setPar、LYCamera.getRequestUrl、Request.Builder.url、OkHttpClient.newCall / Call.enqueue；
  - cmd3014 位于 LYCamera.getSettingDefaultValue (code_off 0x18c3f4)，作为可读诊断，**不将3014误判为一定是当前已选尺寸**。
- 我们原先真机读回照片 5888×3312 ≈19.5M，与这些标准C110配置最高15M存在差异，可能是固件分支、模式或 JPEG 图片插值；**不能保证1002/par5一定落到2560×1440**，只有新拍 SD JPEG 的真实长宽能证明。原厂的照片尺寸和云端上传缩图是两回事。

## 实验包

- 独立模块 :c110photosize；包名 com.vobich.bluestar.c110photosize；版本 0.1.0-c110-photo-native-size-lab，独立 launcher APK，无需覆盖旧版。
- Android 权限仅 INTERNET + ACCESS_NETWORK_STATE。没有访问系统照片/存储权限、相机/麦克风/位置/蓝牙权限。必须**事先由用户在系统Wi-Fi中手动连接C110热点**；不修改原v0.1.20连接方式。
- ① 只读探测：从真实 Wi-Fi 的 Network 对象通过3012确认标准C110，3002检查是否声明1001、1002，3014只读观察返回状态和体量；不记录敏感ID/照片路径。
- ② 拍一张原设置照片：读取3012/3002，按已有6轮真机成功的逻辑切到3001/par0照片模式，在DCIM列原图基线，然后发送**恰好一次**1001快门，轮询新增的**唯一**JPEG路径，读取完整JPG，核对SOI/EOI及BitmapFactory.inJustDecodeBounds结果，只在内存保留尺寸、字节数和耗时，不将照片存手机，也不传云。
- ③ 独立按钮确认后，才可在 3002 声明1002且3012确认标准C110 的前提下向相机发送 **一次** /?custom=1&cmd=1002&par=5（本APK仅唯一候选）；不自动重发、不配置其他参数、不修改视频/预览。此设置可能**持久生效**，因为尚无法安全读取已选设置的原始参数，程序**不猜测、不自动回滚**。用户可按原厂App中的图片尺寸设置将其恢复；不要使用复位出厂设置。未点击③时没有1002写入。
- ④ 再拍一张真实原图，报告与②的宽、高、字节数、照片下载耗时、原厂2K2560×1440目标是否精确匹配。指令Status=0≠已改变写入尺寸；若②和④均已2K，结果不可归因。
- 仅在前台用户单次确认操作时运行；每次切换阶段独立执行，页面离开取消；没有自动循环拍照、没有3002外未知命令、没有删除或格式化、没有云端。
- 诊断仅内存存储，点击「复制全部诊断」后用户自愿发送，不上传 JPG、路径、Wi-Fi 密码或身份信息。

## 推荐首轮验收步骤

1. 保持所有已有蓝星测试包不变；开 C110 热点，并在Android系统Wi-Fi **手动连接到 C110**。
2. 打开独立「C110原生照片尺寸实验」，点①只读检查。若1002未被3002声明，③保持禁用，先将检查日志发来，绝不强行发。
3. 点②以原厂当前设置拍一张（SD卡会新增测试照片），记录真实长宽。
4. 点③阅读警告并明确确认（原厂3M/2K候选 par5，设置可能长期保持）；系统只发送一次设置命令。
5. 点④拍另一张，比较SD原始JPEG真实宽高。若不是2560×1440，记录而不以"2K成功"报告。
6. 点「复制全部诊断」把文字发来。**实验结束用原厂 SJCAM Zone 检查拍照分辨率设置并按需要恢复原档**。本实验没有删旧文件、不会自动恢复固件设置。
7. 后续才能在真实固件确认尺寸参数映射的基础上扩展1080/720等档位，或做自动设置还原。**不要在未验证固件上用未知index枚举写入**。
