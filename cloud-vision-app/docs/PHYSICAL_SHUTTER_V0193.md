# v1.0.93 实体快门自动朗读、可选自动删图、关于软件
基于已发布正式版v1.0.92 04e3d542900e5ae2c9b2e2169c15cfe2ba95b939，原包名、主页六宫格、底栏、灯光/电量、Wi-Fi、预览、手机/USB、模型、任务与TTS不另改。用户真机确认实体快门在Wi-Fi已连接时可拍照、不断开，官方App能看到缩略图；蓝星自动发现新JPEG尚待真机验收。
- 统一设置→相机→C110 运动相机：实体拍照自动朗读默认关，100/200/300/500ms，默认300。自动删图默认关，首次开启确认不可恢复。返回主页后亮屏前台监听，连接/断开/离开/手动快门/AI/灯光等需重新建立基线。无锁屏服务、不新增权限、不改变机身模式、不发送1001、不打开RTSP、不新增Wi-Fi租约。
- 每次新会话验证3012标准C110，完整DCIM目录HTML（包含已知PHOTO路径、限制目录数量），两次有效快照只建立历史集合。轮询单线程无积压，下一轮在请求结束后等待所选间隔。实际检测延迟包括HTTP耗时，不等于100ms。目录异常、结构变化或重连重新建立基线；期间照片可能被跳过，宁可漏读不误上传旧图。发现新路径即取消前一实体识别，完整JPEG未写完只重试GET，最长20秒候选窗口；多图同轮仅选文件名排序末项（不保证真实时序），不自动删除任何多图歧义候选。保益/手机快门或其他页面时停止监听/重建基线，以避免同一照片重复识别。
- 复用C110QuickShotController的C110FrameReader和叮声、原上传分辨率/蜂窝网络/当前任务/模型/语音。诊断c110_physical含目录查询、设置间隔、JPEG下载、发现后取图耗时、云端首字和TTS onStart；onStart仅引擎通知非实际声响，不虚构实体按下时间。
- 删除只限开启后同一有效会话中唯一新JPEG，完整下载、正常非空识别结果完成、请求ID仍有效且删除开关仍开启。目标查找结果、取消、空文本、错误、多张歧义、旧照片、离开或断线均保留。复用历史原厂DEX证据C110DeletePolicy严格路径和URL编码；3012标准身份、3002声明4003、目录存在、重新下载SHA256相同、当前网络和会话许可后才发送一次4003精确文件指令，再只读目录核实。绝不重试删除、批量或格式化。删除是后台相机IO，在朗读请求之后且下一轮没有新候选时执行；可能占用数秒目录查询，不影响已提交云端/TTS。新照片在已经发送的删除期间仍无法取消已发出的命令；谨慎用不重要照片首次实测。实际4003固件能力仍未验证，未声明则安全跳过。
- 设置底部关于软件：PackageManager读取真实versionName/versionCode，BlueStarReleaseInfo记录更新日期及本次更新。今后每次发布必须同步更新BlueStarReleaseInfo.VERSION/DATE/CHANGES与Gradle版本、交接记录，CI校验一致。
- 真机步骤：先关闭删图，设置300ms打开监听，回主页等就绪，按实体快门10次；对比100/200/500ms及日志，验证连续拍照与保益互不重复。再只用不重要照片开启删图，官方相册确认仅本次成功识别图消失且旧照片保持，失败/取消保留；无法删图时提供诊断，不绕过4003声明。验证关于软件版本、语音和其他原有功能。无锁屏运行保证。
