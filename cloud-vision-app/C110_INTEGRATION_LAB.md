# C110 Wi-Fi 高清拍照 → 蓝星向导云端识别朗读接入测试 v0.1.0

**基线**：`feat/bluestar-125-reading-entry-pages-actions-20261108` 原正式 RC25 源码；此处为隔离分支测试包，不更新/覆盖 RC25。复用 2026-11-18 C110 v0.1.3 **六次**真机成功的 `3001&par=0` 照片模式初始化、`1001` 遥控拍照、HTTP DCIM 目录新增 JPEG 完整读取逻辑，不重复旧协议逆向。两次在保持照片模式下直接1001成功。

## UI 和实际流程
- 启动后可见顶部 **C110拍照** 按钮，原本手机/USB相机画面与任务/AI对话/阅读/设置保持不变。
- 系统设置里先连接 C110 热点，网关必须为 `192.168.1.254`；手机**移动数据必须打开**；在测试包设置页自行填入 API Key（旧 RC25 的 Key 不会迁移）。
- 根据当前选中的蓝星视觉任务，单击 C110拍照：单次检查设备3012、能力3002及旧JPEG基线；第一次发一次 `3001&par=0`，以后同一 Wi-Fi Network 直接发一次 `1001`；寻找此次新增原 JPEG；JPEG完整性校验并直接交原 RC25 视觉模型/C 流式朗读。**不保存本地相册**，不将JPEG重复压缩至720p。
- 只有用户点击按钮才拍照，代码没有持续自动拍照、固件OTA、删除、格式化、切回放、切换RTSP。长按 C110拍照 按钮可手动让下次重新初始化照片模式；相机重启/快门-13后需要重初始化。
- C110 HTTP 走所选Wi-Fi `Network.openConnection`，不调用全局 `bindProcessToNetwork`。云端使用移动网络 `Network.openConnection`，避免 C110 热点无外网导致云端请求失败。仅 `192.168.1.254` 允许明文HTTP，云端HTTPS保持加密。
- 保留原本 USB、Camera2、书页管理、云端任务、云端 OCR 模型选择、TTS 配置和语音追问。

## 真机验收范围（**目前未验收**）
- 检查安卓16系统是否同时提供相机Wi-Fi与可验证的蜂窝网络；若未找到蜂窝则提示而不拍照。
- 确认 C110 初次模式切换及以后不切换连拍、JPEG完整字节数、每阶段耗时；异步取消/手机息屏后是否安全。
- 原图接入云端后的文字识别和本地TTS是否正常出声；确认百炼云端是否接受原图像素与计费。
- 提醒：目前接入的是**高清照片第二通道**，并**未**独立接管 C110 RTSP 实时预览码流。原界面显示的手机/USB预览不会自动变成C110实时视频画面。
- C110按钮不接阅读书页存档流程（可在后续版本单独适配），避免破坏 RC25 阅读逻辑。选择「朗读文字」任务可验证云端文字朗读。
