# 蓝星GPU实验室 v0.1.3 独立修复版
v0.1.2真机6轮均在CPU4阶段失败，未到达GPU，下载报ProtocolException/SocketTimeoutException，不能据此判定GPU不兼容。以已通过真机的v0.1.1 CPU加载配置为基准，恢复原始模型设备选择与CPU上下文参数，Vulkan静态注册及动态扫描均跳过，只有语言模型成功加载后的GPU视觉测试才注册Vulkan；释放模型、上下文与视觉对象后移除Vulkan注册表项，不卸载静态链接驱动库。若GPU驱动发生native崩溃，前面的CPU日志已同步保存。驱动本身的全局状态仍可能常驻，因此不声称完全独立进程。GPU上下文仍禁止LLM卸载；单切片、贪心、原分段计时不变。CPU4/6/8、GPU视觉、同图1冷2暖保留。新增阶段、native返回码和上次中止阶段，不记录图片/识别文本/路径。11=无GPU、12=注册异常、13=未编入Vulkan、14=视觉初始化异常；其余按llm_load/vision_load/context_prepare原生阶段解释。未确认实际故障原因，真机必须复测。
签名与v0.1.2比对，一致则原GPU包升级（versionCode 2），否则独立.gpu.recovery包并存。保留原模型目录、哈希；迁移脚本优先原GPU包，其次.speed、旧离线版。不要卸载旧版；迁移需要约1.78GB额外空间，脚本未真机验证。CI编译通过不代表手机CPU/GPU推理通过。正式蓝星向导不改。建议先CPU4/6/8，再CPU4/GPU；如果失败复制新阶段日志。
