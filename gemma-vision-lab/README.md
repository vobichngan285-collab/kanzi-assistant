# 蓝星 Gemma 560 CPU 恢复验证 v0.1.6

v0.1.5 真机出现随机英文、多语言乱码和 unused token。此版使用原厂 LiteRT-LM 0.18.1 Android 运行库，视觉和语言均走 CPU。模型仍使用已验证的 560 修复权重，语言权重及 tokenizer 由原厂模型逐段复制。保留原图输入、默认 560 预算和离线朗读。

安装独立实验包 `com.vobich.bluestar.gemmalab.vision560.recovery`，导入原厂 280 模型并预留约 3.1 GB 空间。用此前出错的同一张价格表，以 560 预算检查完整识别文本、商品及价格，记录首字和总耗时。先确认真机识别，再用同图、同预算比较 GPU 路径。
