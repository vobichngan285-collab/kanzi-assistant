## 本地反事实视觉裁剪（不进行REC）

这张手机图原始横向价格行几何中心高度约 668、710、753px。保持横向，只对可疑内容区域做3次短条裁剪（与原来的3个“纵向旋转裁剪”做肉眼对照）：

- **原 SDK 纵向框裁剪**：把3或4个不同横排的字符按竖向串接，识别器当成一行。
- **影子横向条带裁剪**：每条按周围价格行的 y 中心裁切，可肉眼看到一行内的多个横向字符。裁剪并不是用户手机 SDK 自动提供的“正确文字框”，宽度来自针对这张照片的本地可视化取值，并不代表已证明通用性。
- 私人原图、12/24 crops 与本地蒙太奇**只在当前对话工作容器，不上传 GitHub，不写入 CI**。没有运行 REC 或人工逐字 GT，因此**不能声称减少了多少错字、提升 CER，也不能自动替换朗读文本**。
