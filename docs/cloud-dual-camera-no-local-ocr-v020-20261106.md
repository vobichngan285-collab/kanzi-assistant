## 用户纠正与实施范围
用户指出v0.1.0丢失原有手机相机、改变布局，要求恢复以前的双摄像头显示，仅移除本地OCR。已从2.0分支 `release/blue-star-guide-2.0-20261106` 核查并移植手机Camera2控制器 `InternalCameraController.java`、NV21旋转助手 `Nv21Rotation.java` 和 `PhonePreviewGeometry.java`。所有修改仍仅在 `exp/cloud-vision-usb-click-v1-20261106` 分支的 `cloud-vision-app/` 独立工程。

## 本轮具体改动
- 保持2.0黑色全屏预览、底部三列深色悬浮按钮和暗色设置对话框的框架。左按钮由“模式”改为“任务”，中按钮由“开始识别”改为“点击拍照”，右按钮仍为“设置”。
- 设置→摄像头完整保留2.0的三个选项（USB外接、手机后置、手机前置），保存 `phone_camera_source` / `phone_camera_front` 选择；不再使用v0.1.0单USB滚动页面。
- USB预览保持AUSBC 3.6.0 Native NORMAL / TextureView，1920x1080请求和MJPEG，preview FIT；新版本约5Hz NV21帧回调仅用于**手动**取图，不运行识别模型，不改变UVC视频预览帧率。
- 手机前后摄像头使用2.0原有Camera2控制器、原有SurfaceTexture挂载顺序（`super.onCreate`之后才附加手机TextureView）、传感器旋转及全帧FIT矩阵；不对整个画面进行中心裁剪。
- USB和手机用同一个最新帧的单次点击抓取和JPEG内存压缩路径，保留1500ms防重复点击和1400ms新鲜帧门槛；任务预设和本地自定义功能继续存在。
- 无本地OCR依赖/模型、无`INTERNET`权限、无AI Key；模拟TTS明确说尚未接云端，**不会朗读真实照片文字**。API账号在准备好安全代理后再开通。
- 保留旧2.0、1.0.9、1.0.10分支和历史APK；不将本测试版作为稳定正式版。

### 二、任务选择 UI
- 全屏相机显示保持2.0已调试的摄像头预览与触摸逻辑，不再使用0.1的滚动页面。
- 点击任务入口后，**屏幕中央弹出 3×3 九宫格**（不是横向滚动排列，也不是竖向文本列表），**大图标+清楚的中文任务名**，蓝星地球品牌深蓝/半透明/精致圆角卡片；暗色面板但确保对比度和TalkBack可读。
- 默认显示前述六个入口，不强凑满9个，不添加用户未授权的系统预设任务；用户新建的自定义任务有单独图标，可进入九宫格；超过9个项目分页，不缩小按钮。
- 选择后立即收起九宫格，记住任务。自定义任务支持新增、命名、编辑、保存、删除和选图标；不要求懂Prompt。

### 三、相机、单击取图、提示音和反馈
- **原版USB Native直显**与手机**前置/后置Camera2**均保留，摄像头选择及记忆、USB MJPEG/FIT显示、帧比例、画面0/90/180/270度旋转、水平镜像、USB左右校正、垂直翻转均应复用已通过的技术方案。历史1.0.9/1.0.10/2.0稳定包不改。
- **60 FPS 是USB可支持时的优先预览目标**，不可将NV21单帧采样回调约5Hz误当成视频预览帧率；需用户USB相机真机实测物理更新FPS，不得宣传60FPS已验证或保证所有分辨率都60FPS。云端识别仅点击才拍一张，不连续上传，不让推理阻塞预览。
- **删除“USB画面鲜明色彩”开关及对应额外色彩增强**。之前用户明确修正这个功能没有用。保留“USB画面左右校正”、“垂直翻转”，并保留“附加水平镜像”。
- 相机画面上**单击任意非控制区域**→获取一张最新画面→按选中任务调用相应云端接口→自动朗读；不要要求再按“点击拍照”实体UI按钮。菜单/设置覆盖层打开时触摸只操作对应控件，不误拍。
- 触发立即保留以前调好的**“叮叮”金属提示音 + 手机短振动**；分别有开关，默认开启，必须在云端返回前本机即时反馈。连续误触限制，主动重拍可以执行；不存储敏感照片或识别文本到日志。

- 主设置导航：**语音与语速**（一个入口，下分本地/在线独立控制）、**任务管理**、**摄像头设置**、**提醒与反馈**；开发者诊断可放次级入口，不能让普通用户面对过量技术选项。

### 五、语音配置：本机已安装与在线AI并存、速度**分别保存**
- **完整保留检测/枚举当前手机已经安装、可调用的 Android TTS 引擎**，包括“跟随系统默认语音”，可选具体引擎/试听。不得改全局系统语音设置，或把已安装语音包误当成本应用须下载的模型。
- 本地TTS：继续保留**跟随语音包自身语速**开关；选择本地自定义语速时滑块 **0.50～3.00 倍**、默认 **1.00 倍**，建议步长0.05倍，支持即时试听。真正3.0倍取决于具体引擎。
- 在线AI语音：拟支持阿里云、火山引擎多个音色，可选/试听，**在线语速为另一套独立配置，不得与本地3.0倍滑块共用或相互覆盖**；各模型接受的速度上限/下限需接入时核实。
- 在线失败或网络断开，尽可能回退用户选择的本机TTS（只对已取得的文字可朗读）；本机与在线云音的费用、网络条件分开说明。保留原本“叮叮+振动”，提示反馈不能依赖云端TTS。

### 六、云端任务与追加提问
- 用户只需选**任务**，无需手工选OCR/VL。普通文字走云端OCR；餐厅、医院、店铺、商品、自定义统一走云端高性能VL。不默认先OCR后VL再调用两次。
- 对短文字/路牌使用云端OCR；菜单小字可能需要比固定720P更清楚的单帧：采取任务/清晰度自适应图像压缩，先用真图A/B验收，不为省token让小字看不清。
- 单次点击=单张新照片=一次选定AI任务，收取一次按量请求；添加防误触节流、可查看调用次数/成本、预算上限、隐私提示和必要的云端许可。密钥不能嵌入APK或上传GitHub，接入前需由用户自己开通百炼/预算并建立安全后端。
- **连续追问场景**：第一次视觉识别+朗读之后，用户可以问“哪几个菜不辣”“这些商品哪个便宜”等；在当前临时会话保留必要的图像/识别结果上下文，优先通过文字追问+已有结果完成回答，必要时在授权条件下用原照片再次分析；新单击拍照开启新轮，清除上一轮会话。看不清的证据不猜测。
- **追问触发的交互草案：** 在预览非控制区域长按说话、松手提交（或其他无障碍等价触发，待真机操作体验确认），本机/云端语音转文字后让模型根据当前上下文回答，再自动TTS朗读。用户认可追加追问能力，但长按与双击的最终手势还未单独敲定，**不要当成已经实测或最终锁死的操作**。
- UI仍以盲用友好为先：大按钮，内容明确的TalkBack标签，尽量少步骤，反馈立即。避免一张图又长篇解释又重复朗读。
