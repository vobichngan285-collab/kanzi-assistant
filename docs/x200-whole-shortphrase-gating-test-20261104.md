# X200 实时短文字完整句子：第二张实拍图Small REC扰动与独立公测

2026-11-04。实验主旨：仅清晰短横排、从左到右从上到下；保障整行原样与价目名称＋金额一起输出，不删除词中个别字。书页模式另设；本试验不改正式安卓APK。

## 已真实执行（用户私人图片全留在本地，不进GitHub）
- 对另一次较远距离拍摄的真实价目表照片，人工视觉对齐正确完整ROI后，用官方SHA固定PP-OCRv6 Small REC重新识别10对名称＋金额，89个字符，10对完全正确。此仅说明**获得完整ROI后识别器能够正确识别**，不是自动DET准确率；ROI经过人工校正，不是盲测。
- 对同一图的10个固定完整ROI进行中等合成模糊sigma2.6：原本10项全部输出仅3项全对、字符CER12.36%；置信度门槛0.90后只读5项、只有2项全对，所读字符CER6.12%，但整页GT字符覆盖由100%掉到55.06%。因此条件CER下降不能宣称原文总体识别率提高。
- 强模糊sigma3.5：原始10项都错，字符CER51.69%，有3项数字错误；0.90门槛整10项全部停播，覆盖0%，不能实际使用。
- 将名称ROI右边裁去18像素（原完整内容被截断）：10项都缺少正确原文字符、总字符CER11.24%；但10项模型置信度仍然通过0.90门槛，10项照样播报，整句准确率0%。**高置信度绝不能保证句子完整，必须在模型识别前检查是否有裁切截字**。
- 控制性50%缩小后恢复：不门控10项全部正确，0.90门控却暂缓1项（字符覆盖86.52%），展示纯阈值的漏报损失。全部模糊、裁切为人工合成扰动，同一物理招牌、单张较远拍摄照片，不是独立户外场景。
- 全部明细CSV、源码与报告保存在用户私人会话容器：kanzi_short_phrase_integrity_validation_20261104.zip；不要将用户图像、GT明文或细节上GitHub公共仓库。

## 研发决定
1. 首要解决第一次DET把文字行错框、错截问题，必要时判断ROI边缘文字是否被切断；否则绝不能保证完整句子。不能靠语言常识补造缺字。
2. 保持整个可信短横排原文、价格数字与名称成组朗读，方向从左到右从上到下。
3. 暂不在正式APP设置置信度硬门槛0.90；因为它既可能漏报、全静音，也可能放行高置信度的残缺句子。
4. 后续真正评价同时列出整句正确率、GT覆盖、数字误读、漏读、延迟与手机热状态。无独立完整样本之前不发布正式识别升级。
