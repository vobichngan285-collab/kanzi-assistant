## 1. 应用定位与稳定能力

定位：视障友好的随身 AI 视觉向导。手机/USB摄像头实时预览 → 单击非控件画面抓拍一张图 → 云端 OCR 或视觉大模型识别 → Android 本地TTS尽早朗读，允许就刚才图像进一步语音追问。极简操作，结果保留原文，不臆造。

保留已获用户实测的 v0.5.0 识别链路：
- 阿里云百炼北京端点：\`qwen-vl-ocr\`负责“朗读文字”，\`qwen3-vl-plus\`负责其他任务。Plus为默认，Flash只能在用户核实独立额度与用完即停后手动切换；不自动切到未知费用模型。
- SSE流式视觉文本与本机分句TTS；OCR优先保留已证实有效的既有Prompt、解析、准确率与速度。禁止自作主张换本地 OCR 或引入复杂版面补救。
- 清晰画面优先720p，只有有必要保留细节且原始帧足够大时使用原生1080p。设定可覆盖固定720/1080，避免无意义插值放大或二次重复AI请求。
- 用户曾测视觉首句就绪约791–1125ms，本机TTS引擎启动约840–1186ms、实际开始听见约1秒稍多。此为少量实测，不是稳定保证。保留可选诊断，不能用静态编译代替真机A/B。

## 2. 主界面与三个底部按钮

- 使用现有蓝星地球品牌图标、深蓝背景、淡地球水印、大字体、干净圆角、适当半透明的有质感设计；主界面首先以摄像头实时预览为主，不显示多余开发解释。
- 底部固定三个**适当增大、但不遮挡大量预览**的可触达按钮：**左「任务」｜中「AI对话」｜右「设置」**。设计参考高度约72–80dp，可根据实际设备与安全区域调节。删除中间旧“开始/拍照”按钮。
- 普通状态点击摄像头画面非按钮区域：抓拍当前一张图，立即播放原有“叮叮”声并短振动（声音与振动各有设置开关），发送一次云端请求，自动用本地TTS朗读结果。节流防误触；工具栏/弹出层手势不能触发拍照。
- UI按无障碍与单手操作设计；底部按钮动作始终与显示一致。

## 3. 左侧「任务」→无外框、桌面式任务浮层

- **默认隐藏**，不是开屏就显示六图标。**单击左下「任务」才弹出**。
- 不做包裹所有图标的“大框/模态大卡片”；摄像头预览仍在下方、轻微压暗；“选择任务”简短轻标题及关闭入口。
- 六个项目**像手机桌面**直接排在屏幕中间、每个图标有独立彩色圆角背景及清晰文字。初始**3×3格**，不为增加任务而缩小既有大图标；超过9个任务左右分页。
- 选择某个任务立即关闭浮层、恢复实时预览并记忆当前任务；界面浮层期间不得误拍。
- **准确保留五条预设任务和入口的用户确认原文：**

| 任务 | AI要做什么 |
| --- | --- |
| 朗读文字 | 识别清晰文字，按正确顺序原样朗读，不解释、不分类 |
| 餐厅菜单 | 识别菜名、价格、菜品类别，找出明确标注的招牌菜和推荐菜 |
| 医院科室 | 识别科室名称、楼层、诊室编号、方向指示 |
| 店铺招牌 | 重点识别店名、经营项目、招牌文字和明确显示的特色 |
| 商品信息 | 识别商品名称、品牌、规格、价格、生产日期等可见内容 |
| 自定义任务 | 用户自己编写、保存、编辑 AI 识别指令 |

- 删除实验版的“逛商场”“场景识别”预设；它们不能回填正式版。
- 以上前五个为系统预设任务，最后一个为自定义入口；朗读文字使用云端 OCR，其他任务用视觉模型。看不清的内容不猜测。

## 4. 在「设置→任务管理」编辑全部预设提示词

- **五个系统预设任务的AI提示词都必须可由用户在设置中手动查看、编辑、保存并真正影响后续云端请求**。不是纯展示或被CloudVisionClient硬编码覆盖。
- 每个预设有独立的用户覆写配置；点击「恢复默认」回到上述精确默认文字；升级后保持用户修改内容，不得重置；不必改变预设图标和系统任务主名称。
- “自定义任务”支持新建任务、编辑任务名称和提示词、选择或更换图标、保存、删除；任务自带个性图标，新增后自动参与九宫格分页。
- OCR与视觉模型的基本路由固定，编辑提示词不私自改变路由；系统通用的“仅依据看得清的内容、不编造”约束可叠加，但不可遮蔽用户任务目标。

## 5. 摄像头：复用稳定底层、方向独立记忆、双指变焦

- 保留手机后置/前置Camera2，USB原生AUSBC NORMAL/TextureView 直显，支持摄像头切换与USB/手机独立设置。原生USB预览帧率不由获取AI单张截图的帧回调频率决定；硬件支持时希望60FPS，但不作未验证保证。
- **每个摄像头独立保存方向与镜像/垂直翻转**：手机后置、手机前置各自默认正立，USB设备（按USB厂商/产品ID或可区分设备标识）保存对应的0/90/180/270°校正和镜像等状态，用户的外接USB摄像头此前必须手动转90°；首次校准一次以后插入或切回自动恢复。不能使USB 90°影响手机后摄竖直预览。
- **屏幕所见与上传云端的 JPEG 一致**：方向、左右镜像/垂直翻转与实际照片内容对应。不能只修预览而把侧转/倒转的原始NV21发给AI。
- **双指张开/捏合实时平滑放大缩小**，默认1×，常用上限暂按3×，不超出硬件/画质合理范围；手机优先使用Camera2合法变焦，对应预览与ImageReader同步；USB保留原生采集，显示层缩放并按同一放大窗口裁切所上传照片。无需复杂AI裁切方案，不能声称数字变焦让原图新增真实细节。
- 变焦期间的多指触摸、手势结束不得被识别为单击拍照；浮层任务选择与底部控件不参与变焦/拍照。
- 清除旧“USB画面鲜明色彩”开关及额外饱和度RenderEffect，不修改原生画面其他必要校正。

## 6. 中间「AI对话」：对上一张图一键语音追问

- 主要职责**不是泛用AI文字聊天**，而是对刚才拍摄并识别的照片进行详细追问。
- 先通过点击预览拍照识别、朗读；接着单击底部「AI对话」按钮，自动启动麦克风聆听；正常说话，自动检测语音结束、识别中文并发送到云端模型；回答自动用本地语音朗读。
- **不用长按、不用松手发送、不需要持续按着屏幕**。后续追问再次单击中间按钮。保留当前图片/识别结果及必要的多轮提问上下文，不臆造看不清的信息。
- 无上次照片时提示先拍照。新拍摄图片后重置图片会话。
- 能用已识别结果/已有上下文回答的则不重复上传原图片，必要时按云端服务实际支持的上下文方式重新提供图像；不能凭空假设云端自动持续记住上张图。
- 语音输入优先使用手机现有 Android ASR/语音识别能力，需明确权限、自动收音结束和状态提示；若该手机ASR需联网应明确说明；麦克风不能秘密持续监听。

## 7. 语音与语速：本地TTS，在线配音暂缓

- 正式版仅保留安卓本地 TTS：查找已安装TTS引擎、跟随系统默认或指定、试听；跟随引擎自己的语速切换。
- 自定义语速 **0.50–3.00×**、默认1.00×，建议步长0.05，真实最大值依引擎能力。识别结果与语音追问答案共用本地朗读设置。
- 阿里云/火山在线TTS音色、云端配音付费、在线播放语速**本版暂不实现**。这不意味着语音追问ASR完全无需联网。

## 8. 设置导航与发布安全验收

- 主要入口建议：**语音与语速、任务管理、摄像头设置、提示与振动、云端AI、高级设置**。高级技术诊断不挡普通操作。
- 使用用户自己在手机安全配置的阿里云百炼API Key的单机测试应严格本地加密保管，不把完整Key/图片内容写入日志、GitHub或编译产物；**公开正式发布前必须设计服务端密钥代理和调用配额/费用防护**。
- 模块验收：手机后摄/前摄、USB插拔往返、自动90°方向恢复、镜像与AI输入对齐、双指缩放与AI图片区域一致、720/1080文本正确性、连续拍摄/语音追问、ASR失败反馈、TTS连播、防误触、无障碍可读性及连续稳定运行。
- 手机真实熄屏、USB持续摄像头使用及物理音量键触发列为后续单独验证，不作为正式版1.0硬性交付；Android系统对后台/锁屏摄像头及物理键存在限制。
- **实施顺序建议**：先正式主UI及任务管理、再相机独立方向与双指缩放、再语音追问、最后整套联调真机验收；每阶段不得破坏 v0.5.0 成功的OCR/云端视觉和本机语音链路。
