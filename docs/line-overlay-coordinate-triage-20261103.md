### 对旧统计 36→34 的解释边界

GT 是公开数据集的文本对象/区域，不是严格“一行一个白框”的用户目标标注。当 ID 3 和 ID 2 原框覆盖不同 GT 对象且组合成一条候选线时，一对一 IoU 指标可能下降，不能据此直接改算法。若结合图像像素与人工单行标注确认需要分开，才应在**隔离分支**提出保守限制并做反例测试。
