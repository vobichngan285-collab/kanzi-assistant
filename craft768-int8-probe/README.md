CRAFT768 INT8 独立真机性能测试（研究用安装包）

定位：完全独立的 Android 实验应用，包名 com.vobich.kanzi.craftprobe，
不覆盖、升级或替代正在使用的看字助手（com.vobich.kanzi）。
不要求卸载现有安装包。不需要网络，未申请互联网权限。不自动上传任何图片或结果。

候选权重：
CRAFT MLT25K 768 输入，静态 QDQ S8S8 INT8，通过9张 DEV 照片校准，
20,946,608 字节，SHA256
9ab885d2f6669b77f70e9c8f68acfbe408c0b051501fd02d94bcaa0c7779ab15
通过独立源码构建时，由CI从上游固定CRAFT FP32模型重新量化，只有SHA通过才能打包。

使用步骤：
1. 在 Android 手机安装 CRAFT768_INT8_phone_lab_debug.apk。
   如系统提示未知来源安装，需要用户自主在系统设置对当前安装来源临时允许。
   不要卸载或覆盖原版“看字助手”。
2. 启动“CRAFT INT8 真机实验”，按“① 校验并加载 INT8 模型”。
   查看是否加载成功、ORT会话加载时间和PSS内存。
3. 建议先按“② 使用内置1920×1080模拟文字图”，然后“⑤ 当前图片单次推理”
   和“⑥ 当前图片连续24次推理”。后者含2次预热，不等于真实摄像头每秒24帧。
4. 再用“④ 使用系统相机拍摄真实图片”，拍摄印刷品、包装、小字体或复杂背景，
   或按“③ 从相册选真实图片”，然后重复⑤、⑥。
   外部系统相机是否支持完整照片写入，取决于手机相机；如果失败可用相册。
   输入图片会等比例留白成1920×1080；CRAFT再把长边缩到768并对齐32。
5. “⑦ 可选：独立试听系统语音（非OCR朗读）”仅验证固定语句的语音通道；
   显示的TTS onStart回调耗时不是扬声器第一字实际发声延迟。
6. “⑧ 导出匿名性能数据 JSON”后，将JSON作为附件发送回来即可分析手机真实
   推理P50/P95、内存、可能的热节流。

注意：
- 本应用只测 CRAFT INT8 原始神经网络的加载、预处理、推理和输出维度。
  没有实现CRAFT文字框后处理，没有Small REC识别真实汉字，
  更没有将视觉文字交给TTS；因此不能借它评价完整朗读准确率。
- 设备实验数据仅在用户自愿点击“导出 JSON”时离开本机。
  JSON包含手机厂商/型号、系统版本、运行耗时/内存/电池温度，
  不包含拍摄图片、文字内容、文件路径或位置。
- 不要将这个实验包当正式读字工具，也不要用于重要场景的无障碍识读。
- 模型来自研究权重，需要另行审查分发许可、著作权及第三方许可后
  才能考虑面向公众分发；这里只构建用于用户本人测试的短期工作流产物。
- Android软件测试仍需在用户手机实际安装并执行后才能得出结论，
  GitHub构建成功不表示手机已实测成功。
