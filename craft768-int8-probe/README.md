CRAFT768 INT8 v0.2 竖屏与文字框独立研究版（ARM64）

这是与现有“看字助手”和上一版 CRAFT INT8 性能测试工具不同的独立应用，
包名 com.vobich.kanzi.craftprobe.portrait。
可以同时安装，**不必卸载原版或旧版测试工具**，保留之前6轮×24次的内存测试数据。
不申请联网权限，不会自动上传照片。只研究检测框，不执行Small REC字符识别。

已经完成的程序改动：
- 从系统相机或相册读取照片时保持原图竖横方向和比例，不再套用1920x1080横屏白边。
- 对横竖任意比例照片将长边缩至最多768，输入尺寸向上对齐32；若原图为1536x2048，
  模型输入通常会变成576x768。与旧版竖图经横屏白边后进入768x448不同。
- 利用CRAFT概率图的文字/连接阈值、连通区域、链接清理、膨胀和最小包围矩形
  生成候选文字框，提供图片预览中的黄色边框和框后处理耗时。
  这只是几何定位，不是汉字识别，也不代表每个候选框都正确。
- 仍可测模型加载时间、24次连续推理P50/P95、进程PSS和温度；输出匿名JSON。
- 模型权重保持上一轮完全相同：20,946,608 字节，SHA256
  9ab885d2f6669b77f70e9c8f68acfbe408c0b051501fd02d94bcaa0c7779ab15。
- 仅适用ARM64安卓。不会替换正式App及其默认OCR设置。

**先完成旧版6轮×24次内存测试，再装此新版进行另一组独立测试。**
旧版操作：
1. 打开你已安装的“CRAFT INT8 真机实验”旧版，使用同一张之前的照片。
2. 在同一个应用会话连续点6次「⑥ 当前图片连续24次推理」；每次看到完成后再点下一次。
3. 中途不退出程序，不换图片、不重新加载模型，也不手动清除缓存。
4. 最后一次完成后点「⑧ 导出匿名性能数据JSON」，将文件发回聊天；
   这样可观察6轮的PSS/速度/温度变化是否趋于稳定。

新版操作：
1. 安装新版独立的“CRAFT INT8 真机实验”，启动按①加载模型。
2. 使用③相册或④系统相机选真实竖屏文字照片。建议和旧版使用同一张原始照片。
3. 点击⑨重建并显示文字检测框，查看候选文字区域与耗时（黄框预览在页面下方）。
4. 想继续测速度可点⑤或⑥；⑧导出本机统计JSON。
5. 将新版JSON与旧版的6轮JSON分别提供，勿混淆；若不能看黄框，
   可以仅提供JSON，我会先分析耗时、候选框数，但不宣称其视觉定位正确。

重要限制：图片可能在解码时为了避免超大内存暂时降采样（长边超过2600时）。
本应用尚未内置Small REC或文字朗读，不能直接验证“实际读对了多少字”。
CRAFT Java几何后处理与原Python/OpenCV后处理在边界像素上可能存在细微差异。
安全场景下仍应使用原有正式版看字助手。
