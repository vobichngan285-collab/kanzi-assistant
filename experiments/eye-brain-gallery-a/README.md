# 眼脑协同自动任务 v0.2.0（独立实验）
- 从已真机初步验证的 A v0.1.0 commit 36325b0fff33082c6e59b47c428c9f1e49107f21 派生；原 Google Gallery 1.0.23 / LiteRT-LM、推理和会话代码不改。原 OCR v0.1.3 模型、源码、CPU4、ROI与列裁剪不改。
- 进入离线AI对话，加载原版Gemma模型。默认快速阅读，选图自动执行 OCR→任务文本→原版聊天发送→流式回答，无填入、确认、发送步骤。任务选择：快速阅读、完整朗读（整理适合朗读的文本）、商品信息、招牌与路标、菜单与价目表、通知与步骤、翻译成中文、自定义提问。自定义先在输入框写问题；其他模式也可附加问题。
- 保留上次OCR原文、待核文字与区域外提示、含加载耗时。空结果或对话状态变化不自动发送，用户可重新选图。相册由用户主动授权选图；不自动后台拍摄，不自动执行模型建议。语音播放继续使用原版按钮，未增加自动TTS。待核字段不自动纠错，提示词不保证完全消除幻觉。
- 新独立包名 com.vobich.bluestar.eyebrain.galleryauto，避免不同CI debug签名覆盖失败及已有模型数据损失；原A及正式APP保留。需要在新包中导入/下载模型，APK不含Gemma。原模型管理需网络，推理本地，Firebase统计关闭，历史可能保存在本机。
- CI 编译签名与模型资产校验、真机自动提交/任务质量/速度待验证。
