# 眼脑协同精简实验 v0.2.3
- 继承 v0.2.2 本地模型列表、极简入口及通知权限移除，八任务自动OCR、90秒OCR会话复用、低内存释放、计时及原厂推理指标。原OCR核心/权重、Google Gallery 1.0.23 / LiteRT-LM 推理、会话、采样及保留原生库不改。
- 面向 ARM64 手机，Gradle 仅打包 arm64-v8a；移除日历权限和 XR、XR耳音、Tiny Garden 三个演示素材目录。停止注册智能相册、视频检索、XR教学、Tiny Garden、剪贴簿、Agent Chat、单轮实验任务；活动任务限 llm_chat 和兼容用户导入模型的 llm_test。共享DI、导航、工具代码及依赖不贸然删除，未启用R8，安装包实际减幅以发布资产为准。
- OCR识别不再弹出遮挡式等待框，仅显示原有行内状态。识别中阻止手动发送并禁用有关输入，自动提交前核对原会话ID与草稿、模型状态；错误或会话切换时不自动发送。错误提示和原始OCR查看保留。未加入主动预加载、自动流式TTS。
- 保留本地模型管理、主动下载、必要许可、原语音/历史/参数配置。仅移除不需要的演示和权限，系统下载状态仍可能显示。不宣称所有联网调用或SDK已彻底去除。
- 独立包 com.vobich.bluestar.eyebrain.gallerytrim，需导入模型；原正式APP与之前实验版不动。CI校验签名、包名、固定模型、本地列表、权限、ABI和删除的素材；真机功能、速度、内存待验证。
