# 眼脑协同提速实验 v0.2.1
- 从已可真机运行的全自动 v0.2.0 08977a0f4e57d02d22a3b85901e39992e6b32b2d 派生，8任务及自动发送路径保留，原OCR模型、源码、CPU4、原ROI及列裁剪不改；原Google Gallery 1.0.23/LiteRT-LM推理、会话、采样、上下文机制不改。
- OCR会话由单独串行worker持有，默认复用，90秒空闲、内存警告、ActivityManager低内存、离开组件或关闭常驻时释放；异常时清理。Android版本/系统内存回调不保证及时。额外内存需真机检查。关闭常驻即可冷启动对照。展示实际OCR端到端耗时、冷热、模型加载及原文详情的解码/检测/识别耗时，不包含脑生成时间。
- 默认快速阅读30～80字为提示词软目标，重要信息不因字数省略；招牌简洁，完整朗读不截断。通用安全提示缩短，原OCR原文和待核保留。开启原版ChatPanel实时性能指标功能开关，仅在原厂指标可用时出现，用户可开启；GPU/CPU与原设置兼容，未强制修改后端、思考、推测解码或模型权重。
- 本次不实现自动流式TTS，原朗读按钮仍可用，以免引入并发与语音错误。提示词不能保证无幻觉。非后台自动拍摄，不执行模型建议。原历史可能保存在本机，模型管理需要网络。
- 独立包 com.vobich.bluestar.eyebrain.galleryspeed；原v0.2.0与正式APP保留。需新包导入/下载原模型。性能提升和稳定性尚待真机确认，CI仅验证构建/签名/固定模型资产。
