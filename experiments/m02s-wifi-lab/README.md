# M02S 一键拍照并取新照片 v0.1.7（独立实验）

## 真机已确认的基线
v0.1.6：vivo X200 Pro / Android 16 真机已能 BLE LE1M 连 M02S、连接AP、成功解析5张照片；用户实际拍摄原图通过Wi-Fi已成功下载并在内存显示：JPEG 3200×2400、481424字节、HTTP200、532ms。拍照指令0x22/0x30之前已在v0.1.3真机成功，但“一键串联”尚未验证。

## 新功能（在已有 BLE + AP 连接基础上）
- 新按钮 **一键拍照并获取新照片**，请先以旧流程连蓝牙，再选择AP精准连接。一次点击后无需另点文件列表或原图下载。
- 按钮先获取拍照前官方AP JSON /app/getfilelist 快照；若失败，不发拍照指令。自动确保AA14通知监听；只发一次已验证官方AA13遥控拍照0x22/0x30，并检查GATT写入status=0；失败或4秒无回执绝不自动重复拍照。
- 写入成功后最多45秒按约1.2秒间隔查询列表。只考虑**拍照前没有出现的新文件名**，不能将老照片列表中的“最新一张”冒充本次新照片；多个新文件且最新时间不确定时拒绝猜测。
- 新文件必须报告足够字节，并**连续两次**在列表中显示相同路径、大小和创建时间后，才尝试下载一次。JPEG/PNG/WebP原图限定从已确认Android专属AP Network+私有网关读取；图片不超过32MB、必须匹配魔数/扩展名、有效分辨率才会内存预览。
- 一键按钮可手动取消。Wi-Fi连接失效或蓝牙断开立即停止；不后台重连AP，不自动发完成通知、不关AP，不上传云端、不写相册、不删除眼镜里的照片。UI清空内存即清掉原始图片字节。
- 保留v0.1.6单次手动查列表和照片预览功能作对照；照片任务期间不允许同时手动读取或重复一键任务。

## 真机测试
1. 退出官方HeyCyan，启动独立 v0.1.7，扫描M02S并连接LE1M，打开AA14通知监听直到status=0。
2. 按一次 **AP 热点精准连接**，确认Android onAvailable和私有网关获取；不要再重复尝试P2P。
3. 此时对准一个**新场景**，点击 **一键拍照并获取新照片**（只点一次）。程序自动采集拍照前列表、发一次BLE拍照、轮询新文件、下载，并在界面预览。
4. 若成功日志应有“拍照前基线获取成功”“AA13写入status=0”“新照片已确认”“一键拍照取图完成”“原图下载并解码成功”，随后有JPEG像素大小和耗时。若超时或失败发新增诊断行即可，**不要重复点击**；不需要提供照片、文件名、SSID或口令。
5. 本版不与正式蓝星向导云AI合并。用户实测成功后再决定如何接入视觉识别朗读。

## 限制
“新文件名出现+两次大小稳定”能排除旧列表误取，但不能物理证明其就是这条指令导致的照片；若同时用眼镜实体键或原厂软件另拍会有因果歧义，测试期间请勿做其他拍照。后台切换到ChatGPT会影响Android定时任务执行，测试45秒尽量保持实验APP前台。
