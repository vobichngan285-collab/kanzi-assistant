# 蓝星 M02S Wi-Fi 常连接验证工具 v0.1.0

独立包名 `com.vobichngan.bluestar.m02slab`，不修改蓝星向导 RC25 或眼镜官方 HeyCyan/StarGlasses APK。

## 目标和边界

- BLE **仅扫描、可选只读 GATT 服务发现**，不发送未经验证的拍照/开启 Wi-Fi 指令。
- Wi-Fi Direct 扫描与手动连接指定眼镜设备；如果设备走 AP 模式，可手动输入已知 SSID/密码并通过 Android 系统授权连接。
- Wi-Fi 连接 120 秒保持实验：使用系统 WiFiLock + 3 秒一次**只读** HTTP GET /app/getfilelist，统计响应状态/耗时/内容摘要是否变化，记录 P2P/网络连接状态；不会读取照片原图、不会删除文件、不会上传数据。
- 此工具只做连通性和会话维持测试，不声称已实现蓝牙遥控拍照或自动传图。即使 120 秒测试成功，也还要验证重复拍摄/获取图片的真正协议和眼镜固件空闲超时。
- 如果没有眼镜 Wi-Fi 热点名/密码，且 P2P 扫描不到设备，无法用这一版独立开启眼镜 Wi-Fi：后续需根据官方 APK 精确还原 BLE 指令后继续迭代。
- 对 HTTP 探测仅允许 192.168.x.x 本地 IPv4 地址，绝不访问互联网服务。日志仅在手机本地显示，不打印完整照片列表或图片数据。
- Android 16 需要蓝牙/附近 Wi-Fi/位置运行时授权、系统位置开关；若需要 Wi-Fi AP 连接 Android 会显示确认框。
- **只在手机前台运行**，不请求后台持续运行和后台定位权限。

## 真机测试

1. 在 vivo X200 Pro 安装独立 APK，允许蓝牙、附近设备和位置权限。
2. 先点“扫描蓝牙”确认能看到 M02S，或者先连接官方 App 再进行实验（注意：官方 App 可能占用 BLE）。
3. 点“扫描 Wi-Fi Direct”，等待设备列表。若出现眼镜相关设备，选中后点“连接选中的 P2P 设备”；若走 AP 模式，输入眼镜的 Wi-Fi 名和密码，点“连接 AP”并确认 Android 对话框。**不清楚凭据则不要猜测**。
4. 连接后让测试工具保持在前台，点“保持连接 120 秒”，尝试点击官方 App 的导入或按眼镜实体键拍照，看测试期间连接是否仍保持以及 HTTP 文件列表的摘要有无变化。
5. 将工具的本地诊断复制发送给助手；不得包含私有照片或账号密钥。
6. “停止测试”释放 WiFiLock；退出工具也清理资源。

## 成功标准

- 是否实际发现眼镜的 P2P 或 AP 网络；
- 成功与否可由 P2P 已连接/系统 Wi-Fi Network 可用、HTTP 200 和文件清单摘要变化独立判断；
- 记录从“连接发起”到“可读文件列表”的实际毫秒数以及 120 秒保持情况；
- 断连时记录 Android 报告的状态，但不能仅凭断连推断“官方 App”或固件是谁触发的。

## 来源

静态检查上传的原厂 APK 得到标识 `GET_WIFI_P2P`、`fileDownloadFinish`、`connectP2pWifitoReceivePhoto`、`app/getfilelist` 等。仅方法名称、字符串**不等于**协议细节，暂不自动发送 BLE 命令。
