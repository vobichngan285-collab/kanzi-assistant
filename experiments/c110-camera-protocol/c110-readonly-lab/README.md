## 新增实验
1. 手机系统连接 C110 Wi-Fi；①只读检查照片列表。
2. 确保相机当前处于可以拍照的状态；②确认对话框后仅发一次 `http://192.168.1.254/?custom=1&cmd=1001`。先只读验证 3012 / 3037 并建立本次拍前基线。
3. 检查 1001 HTTP/可解析状态码；20秒内轮询新的 DCIM 文件，只下载与拍前基线不同的路径；检查 JPEG 完整性、HTTP 长度、解码尺寸，成功才存到 Pictures/BlueStar_C110_Test。
4. ③用于原有旧图只读对照；④用于原厂 App 手动进入回放后的只读对照。

不发送 3001 切模式、2015 预览、删除/格式化/OTA，不上传照片，不自动重复拍照。返回 HTTP200 不代表已落盘；未发现新图不能当成功。一次拍照后的新增检测、连续三轮稳定性、远程模式/光路是否正确仍需用户 C110 真机验证。实验独立包名不覆盖正式版。
