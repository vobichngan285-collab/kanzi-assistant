# 蓝星 C110 模式切换 / 快门 / 完整JPEG 实验 v0.1.3

在原独立实验分支继续验证，不改正式蓝星向导，不刷固件。v0.1.2 用户真机日志：

- `192.168.1.254` Wi-Fi 连接正常，DCIM 列出7张旧JPEG，之前已验证原图下载（1,523,091字节，5888×3312，304ms）。
- `3037` XML `Status=-256`，参考联咏 NT96660《Wi-Fi Command User Guide》错误码表是 `WIFIAPP_RET_CMD_NOTFOUND`（命令不存在），说明C110固件当前不能按该文档通用3037查询模式。停止调用3037。
- `1001` 连续两次 `Status=-13`，参考表为 `WIFIAPP_RET_FAIL`（执行失败），HTTP200不等于拍照成功。20秒没新增JPEG，不要继续把旧图误判为成功。
- 同一份文档明确：`1001`只能在照片模式执行；`3001&par=0`切到照片模式，1录像、2回放（不同机型枚举可能有差异）。这一条件在C110实机上仍未验证。

## 新版界面与严格边界
1. ① 仅只读查询3012、3024（SD卡状态）、3002（可用命令），列7张旧JPEG基线，日志只列状态和计数。
2. ② **必须点击并单独确认**，才发送一次 `3001&par=0`（切照片模式，可能打断预览）；若状态不为0，停止、不发1001。若切换成功，读1003自由拍摄张数，再发送 **仅一次1001** 快门。不自动切回录像、不自动重发指令。
3. ③ 用户确认后直接发一次1001不切模式作为对照。v0.1.2在旧状态返回-13，故默认只需试②。
4. 快门Status非0直接显示原因并停止，无效轮询不再耗费20秒。若快门成功，20秒内轮询新增JPEG并保存完整原图；记录时间和同网络持续情况。
5. ④⑤原有下载和回放只读对照保留。禁止删除、格式化、OTA、云端上传。3001只允许照片模式par=0。实验版有独立包名，不覆盖RC25。

**技术来源**：前期已存 `experiments/c110-camera-protocol/C110_DEX_RESEARCH_AND_20261118_HANDOFF.md`；联咏参考说明： https://www.mputek.store/filedown/Survey3-WIFI-Manual.pdf ，5.1.1、5.3.1及第8章。C110固件并非通用说明书的完全复刻，状态码属强相关参考而非固件源码确认。

**待实机**：点击②看模式切换的真实HTTP/Status，1003能否查询，1001是否恢复Status0，出现新JPEG的延迟，Wi-Fi是否稳定，之后再三轮重复验证。
