# 蓝星 C110 遥控拍照 + 高清取图实验 v0.1.2

## 用户已提供的真机结果（2026-11-18）
- v0.1.0 从相机 Wi-Fi `192.168.1.254` 成功列出7个 JPEG；下载与校验 1523091 字节、5888×3312 图片，304ms。
- v0.1.1 点击「拍照并取图」两次均在 `3037当前模式查询未通过` 处终止，**1001 拍照命令从未发送**。此日志不能说明相机拒绝遥控快门。

## 本版修复（2026-11-18）
- 3012 设备查询 HTTP200/响应检查仍保留，限制已实测相机 IP `192.168.1.254`。
- 3037 为模式状态只读查询。非零的XML `<Status>` 具体语义在此C110固件未实测，不能不加区分就视为快门禁令。v0.1.2 打印 3037 HTTP状态、字节数、数值 Status/Value，仅作诊断，不因此阻拦用户明确确认的单次 1001。
- 1001 拍照仅点击②且确认后发一次；日志打印HTTP/数值Status。即使1001的XML Status 非零，也不重复拍照，只继续20秒只读轮询，以新增JPEG的真实存在/完整校验判断拍照是否成功。
- 沿用拍前旧图基线、DCIM目录GET、JPEG头尾+Content-Length+BitmapFactory尺寸校验、保存系统相册。无云端、无OCR、无切模式3001、无预览2015、无删除/格式化/OTA、无自动重试快门。
- 协议参考 `experiments/c110-camera-protocol/C110_DEX_RESEARCH_AND_20261118_HANDOFF.md`。公开 Novatek 资料将3037称为 `get current mode status`，但并未证实该C110具体 XML Status 值含义。下次以设备真实数值及是否新增照片为准。
