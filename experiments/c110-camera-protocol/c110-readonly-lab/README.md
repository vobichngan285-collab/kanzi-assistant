C110 Wi-Fi 只读取图实验 v0.1.0

只修改原 kanzi-assistant 仓库中的独立实验分支，不动正式蓝星向导 RC25、原厂相机、M02S 或 Windows 项目。

依据：2026-11-15 C110 标准版 SJCAM X / Zone 研究记录、2026-11-17 关键调用链报告与 main/PROJECT_HANDOFF.md。

界面：
1. 连接C110 Wi-Fi后，按①检查网关、发送只读 3012 / 3037 / 3015 和 DCIM 目录查询，建立旧照片基线。
2. 按②只读取已有照片列表中排序靠后的一张 JPEG，不将它当作新照片证据。
3. 按③启动20秒新照片监听，再按相机实体快门。只有列表新增且 JPEG SOI/EOI、HTTP字节长度、图片实际尺寸通过后才保存到系统相册 Pictures/BlueStar_C110_Test。
4. 如果原厂媒体模式成功，而拍照模式不能读图，可切回此实验并用④重新检测，只作只读对照。切换 App 可能导致 Wi-Fi 丢失，应以日志核查。

不发送远程拍照1001、切模式3001、直播2015、删除/格式化/OTA，不上传图片。试验数据不是已经完成的真机验证。不能仅凭HTTP200或取到旧照片认定免切取新图成立。若识别到多张候选仅选文件名排序最后一张，其最新性要靠建立基线与真实新拍进行验证。
